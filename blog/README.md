# Blog

Hugo site with the Stack theme.

## Commands

```bash
hugo serve --buildDrafts --disableFastRender   # dev server
hugo --minify                                    # production build
```

Open http://localhost:1313/.

## Theme

[Stack v4](https://github.com/CaiJimmy/hugo-theme-stack) via Hugo modules.

## Config

All config lives in `config/_default/`.
