Setting sorting layer and order in layer of Mesh Renderer

Sunday, October 30, 2016 1 minute read

Unity 5.x exposes the sorting layer and order in layer of SpriterRenderer, but not MeshRenderer. Fortunately, it’s very easy setting these property of the MeshRenderer in code. I’ve created a simple solution for setting sorting layer and order in layer of any Renderer component using a simple component called SortingLayerSetter.
